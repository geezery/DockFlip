# Keyboard Shortcuts

Mac keyboards have no Win key, so **⌃⌥ (Control + Option) plays the Win key**.
⌘ shortcuts belong to the app you're in, and Globe shortcuts belong to macOS's
own tiling, so ⌃⌥ was the free seat.

| DockFlip | Windows | What happens |
|---|---|---|
| ⌘ Tab | Alt+Tab | Flip 3D window switcher |
| ⌘ ⇧ Tab | Alt+Shift+Tab | Switcher, going backwards |
| ⌃⌥ ← | Win+← | Left half; press again to move on to the display on the left |
| ⌃⌥ → | Win+→ | Right half; press again to move on to the display on the right |
| ⌃⌥ ↑ | Win+↑ | Maximize; from a half, the top quarter |
| ⌃⌥ ↓ | Win+↓ | Restore, then minimize; from a half, the bottom quarter |
| ⌃⌥ ⇧ ← / → | Win+Shift+← / → | Move the window to the next display |
| ⌃⌥ 1…9 | Win+1…9 | Open the n-th app in the Dock |
| ⌃⌥ D | Win+D | Show desktop |
| ⌃⌥ E | Win+E | New Finder window |

## Quarters, the Windows way

Snap to a half first, then go up or down:

- ⌃⌥→ then ⌃⌥↑ gives the **top-right** quarter.
- ⌃⌥← then ⌃⌥↓ gives the **bottom-left** quarter.

Or drag the window near a corner.

## Inside the switcher

| Key | Action |
|---|---|
| Tab / ⇧Tab | Next / previous |
| ← → | Move through the stack |
| Type letters | Filter |
| Return | Switch |
| Esc | Clear the filter, or cancel |
| Release ⌘ | Switch (when not filtering) |

## Forgot one?

DockFlip's menu bar menu → **Window Layout** lists them all. Clicking one
applies it to the window in front.

## Turning shortcuts off

Settings → *Keyboard shortcuts*. The Dock window lists keep working.
