# Welcome to the DockFlip wiki

DockFlip brings the best bits of Windows to your Mac in one small, free,
open-source app:

- **Window lists in the Dock.** Hover an icon to see its windows, with browser
  tabs listed under each one.
- **A Flip 3D ⌘Tab** that switches between windows rather than apps.
- **Snapping** with ⌃⌥ as your Win key, or by dragging a window to an edge.

## The philosophy, in one paragraph

Take what Windows got right. Leave the rest where it was. Don't add a setting
when a good default will do. Never poll, never phone home, never log what's in
your windows. If it doesn't work every time, it doesn't ship.
